# 🛍️ ShopSphere

A modern e-commerce web application built using Python, Flask, HTML, CSS, and JavaScript.

---

# 🚀 Features

- 🛒 Add to Cart
- 🔍 Product Search
- 💳 Checkout Page
- ✅ Order Success Page
- 🎨 Modern Responsive UI
- ⚡ Fast Flask Backend
- 📱 Mobile Friendly Design

---

# 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/shopsphere.git
```

---

## Open Folder

```bash
cd shopsphere
```

---

## Install Flask

```bash
pip install flask
```

---

## Run Application

```bash
python app.py
```
